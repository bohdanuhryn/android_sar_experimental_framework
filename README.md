### Overview

Даний репозиторій містить інструменти для виконання стресових тестів для ОС Андроїд та збору даних системи про використання апаратних ресурсів, виконання процесів системи та застосунків користувача.
Розроблені засоби призначені для полегшення процесу збору даних для дослідження явища старіння та омолодження ПЗ в ОС Андроїд.

### Supported environments

Розроблені засоби забезпечують підтримку таких середовищ виконання команд як:
- `powershell/*` - Windows OS;
- `bash/*` - Linux OS, MacOS.

### Architecture overview

Експеримент - це процес виконання стресового тесту з заданами параметрами і певною тривалістю під час виконання якого виконується збір системних даних з певним наперед заданим інтервалом часу.

Директорія `runs` містить код запуску експериментів:
- `*/runs/debug.*` - це код запуску експерименту для відлагодження всього функціоналу;
- `*/runs/example.*` - це код запуску експеримену, який можна використовувати як шаблон.

Директорія `scripts` містить всі необхідні засоби для побудови експерименту:
- `*/scripts/stress.*` - це код вхідної точки всіх експериментів;
- `*/scripts/workload.*` - це набір функцій для генерування робочого навантаження;
- `*/scripts/monitor.*` - це набір функцій запису системних даних з різних джерел на екран чи у файл.
